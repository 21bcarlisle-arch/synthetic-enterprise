# The map is two files now — the drawn half and the closed half

**Date:** 2026-08-26. **Lane:** LANE 0, the delivery seat's own decision.
**Authority:** director console, 2026-08-24 — *"read those 117, delete what shouldn't exist,
close what's finished, and collapse anything that's bookkeeping rather than work… I'd rather
the map were half the size and true."* Carried in `docs/direction/DIRECTION.yaml` as
`harness-lane-prune` since, with the analysis done and the execution not.
**Undo:** `git revert` of the commit carrying this file. The split moved atom records between
two files without altering a byte inside any record; the union of the two files parses to the
same 298 records the single file did, verified before landing (below).

## What changed

`docs/design/maturity_map.yaml` held **298 atoms in 5,420 lines**. **224 of those atoms
(3,947 lines, 73%) were at or above their own target** — finished work that every draw, every
survey and every reader walked through to reach the 74 atoms that still carry a gap.

The finished atoms now live in `docs/design/maturity_map_closed.yaml`. The drawn file is
**74 atoms in 1,473 lines**. Nothing was deleted and no record was edited by the move.

| | before | after |
|---|---|---|
| `maturity_map.yaml` (the DRAWN map) | 298 atoms / 5,420 lines | **74 atoms / 1,473 lines** |
| `maturity_map_closed.yaml` | — | 224 atoms |
| the map (what a reader gets) | 298 atoms | **298 atoms** |

## The split predicate, and why it is that one

`tools/maturity_map_store.is_closed`: an atom is in the closed half when
`level_current >= level_target`. Stated once, in code, so the splitter, the loader and any
later auditor cannot drift apart.

It is that predicate because **it is the one the BUILD draw already used** to skip an atom
(`if not has_gap: return False`). So no atom that was drawable moved out of the drawn file,
and the split cannot have changed what the machine can work on. `closed:` prose on an atom is
a REASON written by whoever closed it — not the test — because an atom can carry a closure
reason and still sit below a target nobody lowered, and the file it lives in must agree with
the draw rather than with the prose.

`tests/tools/test_maturity_map_store.py::test_the_split_predicate_agrees_with_where_every_atom_actually_SITS`
pins both directions on the live tree, so an atom whose target is later raised without moving
its record back reds instead of sitting silently in the wrong file.

## The named hazard, and the evidence it did not happen

The director's own analysis named it: `site/moap_coherence.py` / `site/moap_stage.py` derive
every front-door node's **Live / Building / Planned** stage from atom LEVELS. A reader that
silently received only the drawn half would find no atom at target behind a finished node and
**render it Planned on the public site** — a smaller, plausible, wrong answer.

That is R15's FAIL-OPEN shape exactly, so it is answered by construction rather than by care:

- **One canonical loader.** `tools/maturity_map_store.py`. Every reader in the tree was
  repointed at it (34 call sites across 30 modules and 7 test files). `load_atoms()` returns
  the union; the split is a fact about storage, not about the population.
- **It refuses rather than degrades.** On the canonical path, a closed half that is missing,
  empty, whitespace-only, unparseable, a mapping instead of a list, or a file of comments
  RAISES `MapStoreError`. All six are mutation-tested, with a null control proving the same
  three calls pass when the half is intact — otherwise a loader that raised unconditionally
  would pass every mutation.
- **One deliberate seam, pinned so it cannot widen.** A NON-canonical path (a fixture map)
  with no sibling reads live-only, because a single-file fixture never had a closed half. It
  keys on the resolved canonical path, not on a flag a caller can pass, and a fixture path
  whose sibling exists and is CORRUPT still raises.

**Verified, not asserted** — measured in one process across the split, on the real tree:

- `site/moap_stage.node_stages()` is **identical** before and after. No node changed stage.
- `site/moap_coherence.map_atom_ids()` returns the same **298** ids.
- `tools/generate_maturity_map_data` emits a **byte-identical** `site/data/maturity_map.json`
  — same 298 records, same order, same lane rollups, same totals.

## Three controls the split would have quietly turned fail-open, and were fixed with it

A control whose subject shrinks passes for a new reason. Each of these was caught by running
it, not by reading it:

1. **`tests/design/test_simplifications_store.py`'s map size ratchet** measured
   `MAP_PATH.stat().st_size`. After the split that is the drawn half alone — the ceiling would
   have been met by the SPLIT rather than by the register living in the store, and accretion
   into a closed atom would have been invisible to the one control that exists to see it. Now
   measures both halves.
2. **`tools/pre_commit_test_gate.LEVEL_SURFACE_FILES`** named one of the two files the map now
   consists of, so a level or target edit landing in the closed half would have selected no
   level-sensitive test at all. Both halves are listed.
3. **`tools/level_promotion_gate`** and **`tools/consolidation_rhythm`** compared atom levels
   across one path. Reading one half would let a level move in the other through unrecorded,
   and would read every atom that merely MOVED between halves as a deletion. Both now read the
   whole map at each revision (`_whole_map` / `_whole_map_at`).

`background/tree_lock.PROTECTED_PATHS` and the publisher's pre-gate stage list
(`background/process_run_complete.git_commit_push`) were extended to the closed half for the
same reason: a path that is protected in one half and not the other is not protected.

## An atom that comes back

Move its record to `maturity_map.yaml` **in the same commit that raises its target**. The
store test above fails if the two ever disagree.

## What this did NOT do, and why

The director's instruction had a second half — *"delete what shouldn't exist"*. Nineteen atoms
were deleted on 2026-08-24 (`RETIRED_ATOMS_2026-08-24.md`) under a stated five-part rule. This
pass deleted none. Moving a finished atom is reversible and provably content-preserving;
deciding an atom *should never have existed* is a judgement per atom, and mixing the two into
one commit would have made the reversible half unreviewable. The closed half is now the place
to make that judgement from, which is the point of separating them.
