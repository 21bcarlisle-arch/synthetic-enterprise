## What the shape means

The report is not merely imported — it has become the place where domain figures are
COMPUTED, and the suite validates those figures by calling renderer internals. So the
debt is not an import list to unpick; it is that a rendering owns computations. Paying
it means giving each of those sections a home outside the renderer and repointing its
tests, which is a rebuild of the reporting layer.
