## Why

Several of this autumn's most useful sources were GitHub repositories: DeepSeek's harness, Google's Elephant-Goldfish model, Predbat and NVIDIA's Auto Ontology. Trending repositories often show a practice before anyone writes it up.

But stars measure attention, not quality. Fake stars are documented at scale, with millions suspected in a 2024 academic study. Trending favours the new and viral. The advisor's snapshot of new repositories since 27 Oct by stars was about 4 relevant in 25; the rest were emulators, game ports and media tools.

## Wanted

- **One automated query a week,** for example the GitHub search API for recent repositories by stars, or trending, filtered to our topics:
  - AI agents and harnesses;
  - Claude Code skills and plugins;
  - testing and verification;
  - observability;
  - ontology, knowledge graphs and abstraction;
  - energy.
- **Read at most three properly:** the code and the licence, not the README.
- **Each read goes in the reading log with a verdict.** Grade a repository as *popularity* until its code or its results prove more.
- **First read: `janestreet/agent_skills`.** It is a serious engineering firm's own published practice. Compare it with our skills and CLAUDE.md conventions.
- **Also on this week's list,** for the same reading: `deepseek-ai/dsh-superagent-prototype`, which follows on from the DeepSeek harness we took three ideas from in October, and `KKKKhazix/agent-autoloop`, a background agent that "only asks when unsure", close to our operating model.

## Rules

- Nothing found this way is installed or run without reading it first and checking its licence: Predbat turned out to be personal-use only. The plugin rules of 7 Nov apply.
- A recommendation still goes through normal ranking. The scan never queues work by itself.
- Report the spend in the Monday note line, with the Anthropic sweep.

## Risk

Touches: the weekly sweep, and reading-log entries.
Blast radius: a small weekly spend.
Probable failure mode: the scan turning into a feed of novelty that fills the queue. Hold the cap of three reads a week, and require each recommendation to name the class or measured problem it addresses.
Proportionality: reversible and narrow — just do it.
