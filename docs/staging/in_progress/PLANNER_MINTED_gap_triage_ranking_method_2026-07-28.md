## Exit criteria
- A design doc `docs/design/GAP_TRIAGE_AND_RANKING.md` proposing, with reasoning **and evidence**:
  - **(i) Classification taxonomy** — every enumerated gap lands in exactly one of:
    `mint` (worth closing) · `deliberate-and-staying` (a scope choice, argued) ·
    `blocked-on-director` (closure needs a reserved-wall decision — R13 curriculum, one-way door,
    generator ground truth — escalated, never worked around) · `not-worth-the-complexity` (left open
    with a *better-measured bound* — an honest red, credited per §3).
  - **(ii) Ranking dimensions** (what orders the `mint` set), each with a stated rationale + evidence:
    fidelity impact (distance from a naive baseline / real benchmark), mission relevance (£/tCO₂e
    story, the company's reason to exist), board-battery weight (disqualification-battery items a
    practitioner said make the build not credible), blast radius, cost-to-close.
  - **(iii) Mint threshold** — what score/combination makes a gap worth minting vs. leaving open.
  - **(iv) Deliberate-and-staying criteria** — the explicit test that keeps a simplification deliberate
    (so it is *argued*, never silently fixed or reclassified to be closable — a claim-status defect).
  - **(v) R12 guard** — the doc states, up front, that the number of gaps closed is a diagnostic and
    may never become a score, target, or headline.
- **RETURN FOR RATIFICATION:** because the classification implies scope/curriculum judgement, the doc
  is escalated to the director as an **[ACT]** (NTFY) proposal and **HELD** — the agent does NOT
  self-apply the taxonomy to open/keep any gap until ratified. (This is a genuine "returns for
  ratification" per §2 — not auto-proceed.)
- **Argue-back invited (§2):** if any named mint source is a *poor* one (noisy, stale, superseded), the
  doc says so with evidence rather than dutifully working it.
