(Spec-005 §3) — an ops pane that cannot act is honest, one that fakes a
write control would not be. A third, read-only job is live below: a
delta view — what changed since you last looked. It has two
halves: a durable last-look stamp committed to the repo (it survives
a publish, a new device and a cleared browser) which leads the page, and a
per-device marker saved in your own browser only, kept further down. Neither
is a server-side read receipt of your browsing.
How this pane is gated. It is off-nav and noindex —
unlisted, reachable only by knowing the URL. The view itself is not
behind a lock : it renders read-only repo state, and a client-side PIN
that opened with any key would be theatre, not a control. This pane carries
no write affordance at all . The PIN-authenticated page-comment box was
retired as a director-authority path on 2026-07-24 (director ruling):
a web form staging content as the director's voice was the weakest link in
the authority model, so it was decommissioned rather than redesigned. All
director input now arrives via the advisor bridge or a signed director
channel. Real director writes (repo/keys/curriculum/fitness) stay
console-only (one-way-door categories 5/6/8); the decision battery and stop
control that would need genuine write-auth are deferred this pass, so there
is nothing to fake-gate.
