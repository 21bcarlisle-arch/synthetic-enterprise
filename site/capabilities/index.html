The world

A synthetic Great Britain energy market, built on nearly ten years of real half-hourly settlement data.

The supplier

An energy retailer operating inside that world, which can only see what a real supplier could see.

What is not there yet

Stated plainly, because a capability list with no gaps in it is not a capability list. This includes one gap worth naming directly: the carbon measurement the whole premise rests on is not built.

The seams — where the curtain is

The supplier never reaches into the world; it reads and writes through named doorways, the same way a real supplier reaches the industry. That boundary is the point of the design: going live means swapping a simulated counterparty for a real one behind an unchanged doorway, not rewriting the supplier. None of these connections is built — what exists is the boundary they would plug into.

How solid the boundary is

The boundary is not a promise; it is measured, and the measurement is allowed to be unflattering. Every place the supplier's code and the world's code still touch directly is found by a walker, listed, and given a ruling — cut, or kept for a stated reason.

Every figure on this page is generated from the project's own records at the commit shown at the top. Nothing here is typed in by hand except the descriptions, which say what the code does rather than what any run produced.
