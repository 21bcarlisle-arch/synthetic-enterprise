The evidence behind the model on a page

Every part of the diagram on the front door wears a build stage — Live, Building or Planned. That word is not typed by anyone: it is derived from the levels of the named build atoms behind that part. This page is the primary state that derivation runs on, per part: the atoms and their levels, the artefacts each atom names and whether those files actually exist, how many tests those test files really define, the recorded level moves, and — where the harness has measured one — the belief-vs-truth gap itself. No prose restates a claim here; every figure below is read out of the map, the repo tree and the ledgers at generation time.
