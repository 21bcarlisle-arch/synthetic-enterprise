Proof

The single job of this surface: show that this company corrects itself in public. Not a claim that it is good — a rendering of its honesty made checkable. Every failure is turned into a permanent rule and left on the record; every figure can be walked to the file it came from, under a claim-status vocabulary; corrections are shown in place, never quietly deleted; and anyone can challenge any number here. The Method (how this is built) and the full simplifications register fold in below.

The claim-status vocabulary used across this page
VERIFIED a consumer's fetch confirmed it (R1) — PROVISIONAL real but still moving or externally uncalibrated — PLANNED named but not yet measured, never faked — RETRACTED was wrong, shown struck through with the correction linked (below).

Challenge a figure

This surface exists to be disputed. Any figure on it is challengeable. The in-page PIN “feedback” box that once carried challenges was retired on 2026-07-24 (director ruling): a web form staging content as the director's voice was the weakest link in the authority model, so it was decommissioned rather than redesigned. Challenges now reach the director through the advisor bridge or a signed director channel — never an anonymous, PIN-only web form. A challenge that lands still becomes a correction rendered in place: the figure is struck, the corrected value shown beside it, and — if it forged a rule — a new row in the Incident → Rule timeline below. That is what “corrects itself in public” means here: not that no figure is ever wrong, but that a wrong one is never silently deleted.
